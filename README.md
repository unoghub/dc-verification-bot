# unog-discord-bot

## Features

- Management of form based verification applications
- Management of Welcome Page for newly verified members
- Management of Jam Creation, Team Creation, Commiting Team Games
- In-App Commands

## Installation

- Configure the .env file.
- Use the CLI Command:<br>
```python bot.py```

## Example .env file:

``` 
BOT_TOKEN = Discord App Private Token
TEXTCHANNELID_VERIFICATION_PANEL = Text Channel ID of Verification Panel
TEXTCHANNELID_VERIFICATION = Text Channel ID of Verification Area 
TEXTCHANNELID_WELCOME = Text Channel ID of Welcoming Area
ROLEID_BOTDEV = Role ID of Bot Developer
ROLEID_DIRECTOR = Role ID of Directors
ROLEID_APPROVER = Role ID of Approvers
ROLEID_VOLUNTEER = Role ID of Volunteers
ROLEID_MEMBER = Role ID of Verified Members
SERVERID_UNOG = Server ID of UNOG 
```
